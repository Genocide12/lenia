# Lenia — живая вселенная непрерывной «Жизни»

Интерактивная WebGL2-реконструкция [Lenia](https://chakazul.github.io/lenia.html) —
непрерывного клеточного автомата Бёрта Ван-Чака Чана, «гладкого» потомка игры
«Жизнь» Конвея. Всё считается локально в браузере: без сервера, без нейросетей —
только свёртка, функция роста и ваша любознательность.

**Демо:** <https://genocide12.github.io/lenia/>

## Что внутри

- **Движок на WebGL2** — тороидальный мир 256×256, float-текстуры, поэлементная
  свёртка с кольцевым ядром. Три шейдера: шаг симуляции, кисть, отрисовка
  (билинейная выборка + палитры).
- **14 существ из оригинальной библиотеки** — `animals.json` из репозитория
  Chakazul/Lenia (MIT). Паттерны декодированы из RLE и **проверены эталонной
  симуляцией на NumPy** (`scripts/verify_lenia.py`): каждое выживает и сохраняет
  форму при своих параметрах. Среди них — самовоспроизводящийся
  *Hydrogeminium saliens*.
- **Точные формулы оригинала**: ядро `K(r) = exp(4 − 1/(r(1−r)))`, рост
  `G(u) = 2·exp(−(u−μ)²/(2σ²)) − 1`, обновление `A ← clip(A + Δt·G(K∗A), 0, 1)`.
- **Живые ползунки физики** — μ, σ, R, Δt, форма ядра и функции роста меняются
  на лету; графики ядра и роста обновляются в реальном времени.
- **Сцены**: «Орбии навстречу» (столкновения запускают взрыв колонии),
  «Деление клетки», «Первичный бульон», «Лоб в лоб».
- **Кисть** — рисуйте живое вещество и смотрите, как организмы
  самовосстанавливаются.

## Управление

| Действие | Как |
|---|---|
| Пауза / пуск | `Пробел` или кнопка |
| Посадить существо | клик по существу → клик по полю |
| Повернуть существо | колесо мыши или `Q` / `E` |
| Несколько существ | `Shift` + клик по полю |
| Случайное поле | `R` |
| Очистить поле | `C` |
| Стирание кистью | правая кнопка мыши |

## Почему существа умирают при смене вида

У каждого вида Lenia своя «физика» (R, μ, σ, ядро, Δt). Когда вы вооружаете
существо, мир подстраивается под его законы — обитатели, жившие по другим
законам, обычно погибают. Это не баг, а суть системы: видоспецифичные законы
природы.

## Структура

```
src/lib/lenia/engine.ts      # WebGL2-движок (шейдеры, кисть, палитры)
src/lib/lenia/creatures.ts   # 14 проверенных существ (сгенерировано скриптом)
src/components/lenia/        # миниатюры, графики, образовательная секция
src/app/page.tsx             # интерфейс лаборатории
scripts/                     # пайплайн проверки: декод RLE → NumPy-симуляция → экспорт
```
