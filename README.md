# Lenia — живая реконструкция непрерывной «Жизни»

Интерактивная симуляция [Lenia](https://arxiv.org/abs/1812.05433) — непрерывного
клеточного автомата Bert Wang-Chak Chan. Поле 256×256 на торе, шаг считается
на GPU (WebGL2, float-текстуры), рендер — палитры с гамма-коррекцией.
Всё работает в браузере, без сервера.

**Демо:** https://genocide12.github.io/lenia/

## Что внутри

- **Движок** (`src/lib/lenia/engine.ts`): ping-pong R32F-текстуры, аналитическое
  ядро прямо в шейдере шага, ручной bilinear при отрисовке, тороидальная
  расстановка паттернов с разрезом на квадранты.
- **Зверинец** (`src/lib/lenia/creatures.ts`): 14 существ из оригинальной
  библиотеки `animals.json` (глайдеры, осцилляторы, ротатор, два репликатора).
  Каждое проверено эталонной симуляцией.
- **Сцены** (`src/app/page.tsx`):
  - **Первичный бульон** (по умолчанию) — канонический эксперимент Чана:
    случайное гладкое поле в физике орбия самособирается в экосистему
    из ~180 организмов с курсами во все стороны; столкновения, слияния
    и новые рождения не прекращаются (эталон: население 158–195, масса
    ≈ 12 600 — 6000+ шагов без деградации);
  - **Встречный хаос** — 10 орбиев со случайными курсами: на торе встречные
    пути неизбежно пересекаются, лобовые удары и гибели неизбежны
    (эталон: 10 → 6 → 5 → 3 → 2 за первые сотни шагов);
  - **Деление клетки** — Hydrogeminium saliens, бесконечный цикл делений;
- **Счётчик организмов**: связные компоненты поля (та же метрика, что
  в эталонном трекере NumPy) — видно, как население дышит: рождения
  и гибели в прямом эфире.
- **Авто-возрождение**: если мир вымер (масса ~0), захирел (население
  ниже порога) или замер (масса, центроид и разброс массы стоят на месте) —
  сцена пересевается с вариациями. Ручные правки (кисть, посадка существ,
  физика) отключают возрождение, смена сцены включает снова.
- **Панель физики**: μ, σ, R, Δt, форма ядра и функция роста меняются на лету,
  графики ядра и роста обновляются живьём.
- **Кисть**: рисование/стирание вещества, посадка существ с поворотом
  (колесо мыши, Q/E), множественная посадка через Shift.

## Верификация

Поведение движка сверено с эталонной NumPy-симуляцией (FFT-свёртка, float64):

- `scripts/verify_lenia.py` — декодер RLE `animals.json` и эталонная симуляция;
- `scripts/emergence_test.py` — эксперименты по эмерджентности: подбор
  масштаба шума, трекинг блобов (позиции, курсы, скорости), сценарий
  «встречного хаоса»;
- все 14 существ проверены на выживаемость и скорость, сцены сверены
  с эталонными прогонами (числа — в описаниях сцен в UI).

WebGL-движок дополнительно проверен в headless-браузере: посев бульона
  из шума воспроизводит эталонную динамику (масса ~13 400–13 500,
  население 140–210, разные курсы — подтверждено визуально и по метрикам).

## Запуск

```bash
bun install
bun run dev        # http://localhost:3000
bun run lint       # eslint
```

Статическая сборка для GitHub Pages:

```bash
bun run build:static   # out/ с basePath /lenia
```

## Математика

Обновление поля: `A ← clip(A + Δt·G(K∗A), 0, 1)`, где K — радиальное
shell-ядро (радиус R, веса оболочек b), G — функция роста с центром μ
и шириной σ. Существа — локализованные солитоноподобные решения;
поведение зависит от параметров, поэтому у каждого вида «своя физика».
